# Описание задания
Написание модуля для тестирования функций с использованием библиотеки pytest.

# Структура проекта
В папке находятся два файла:
1. math_utils.py — модуль с исходными математическими функциями (сложение и деление).
2. test_math.py — файл с тестами (начинается с test_, как требует Pytest).

# Что проверяют тесты:
1. test_add_numbers — проверяет корректность работы функции сложения (assert add_numbers(2, 3) == 5).
2. test_divide_numbers — проверяет корректность работы функции деления (assert divide_numbers(10, 2) == 5.0).
3. test_divide_by_zero — проверяет обработку ошибок. С помощью конструкции pytest.raises(ValueError) проверяется, что при попытке деления на ноль программа выбрасывает исключение (в соответствии с классификацией ошибок из 4 Лекции).
